Bewertung der Einfärbung „grau = gestartet, orange = läuft“

Semantik (zwei verschiedene Aussagen)

Grau = Bereitschaft: Der Dienst ist gestartet und die API ist erreichbar — „ich könnte jetzt sofort loslegen“. Orange = Aktivität: In diesem Moment wird ein Request verarbeitet (GPU arbeitet). Das ist genau die Unterscheidung, die das Geräte-Badge seit 2.5.0 schon trifft — die Leiste spricht nur dieselbe Sprache, bezogen auf ein Gerät.

Nur das aktuelle Gerät

Das Symbol folgt der Auswahl im Gerätebereich/Dashboard: gewähltes Gerät = Dev-Server → Punkt zeigt dessen Inferenz-Zustand. Was „aktuell“ heißt, muss der Tooltip nennen („… auf Dev-Server“), sonst liest man den grauen Punkt fälschlich als „überall läuft nichts“. Fenster versteckt? Das Tray-Symbol existiert nur im Hintergrundbetrieb — dort bleibt das zuletzt gewählte Gerät maßgeblich. Nebenwirkung: die Abfrage muss im Hintergrund nur noch ein Gerät sweepen (günstiger als der volle Sweep).

Gewinn

Ein Blick sagt: orange = gleich wird ein Ergebnis fertig / GPU nicht für anderes blockieren; grau = Server lebt, wartet nur (z. B. Modell geladen, nichts angefragt); kein Symbol = nichts läuft / Port zu — ein abgestürzter oder gestoppter Server ist damit sofort von einem idle Server unterscheidbar. Der grau-Zustand beantwortet außerdem die häufigste Frage: „Läuft bei mir überhaupt etwas, oder hat Strata nur Startprobleme?“

Kosten / Risiken

Grau neben dem dunklen Icon ist schwer sichtbar (Kontrast!) — ggf. helleres Grau #b6bcc7. Amber (warn) und Orange (active) sind auf 16 px fast gleich — beim Punkt löst das der hohle Ring (Form statt Farbe), beim Blitz der Schrägstrich. Kurze Jobs (< Abfrageintervall 10 s) können flackern oder unsichtbar bleiben; Zustandswechsel sind bis zu ein Intervalt verzögert. Beim Geräte-Wechsel springt die Symbolbedeutung mit — Gewöhnungsaufgabe.

Plattform-Hinweise

Windows: Overlay auf das 16×16-Icon (48×48-Bitmap rechnen, DPI beachten); Tooltip nennt immer das Gerät („Inferenz läuft gerade auf Dev-Server (Strata @ :8080)“). macOS: Menüleisten-Symbole sind eigentlich monochrome Template-Images — Farbe wird dort nicht zuverlässig dargestellt. Fallback: Punkt gefüllt (läuft) vs. Ring (idle) vs. Ring+Strich (warn) statt Farbe, oder bewusst farbiges Nicht-Template-Icon (wie im farbigen Mock oben). Beachten: Das Tray-Symbol existiert heute nur, solange das Fenster versteckt ist (close-to-tray) — die Anzeige gilt also für den Hintergrundbetrieb mit dem zuletzt gewählten Gerät.
